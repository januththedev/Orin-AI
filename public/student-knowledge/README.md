# Orin Student Knowledge

50 academic foundation datasets (20 O/L, 30 A/L), plus 8 practical Sri Lanka student guides. Total: 332 original Q&A records.

Subject-teacher review pending. Not complete curricula; not official past papers or marking schemes.

Core subjects are split by topic; related electives are grouped. A subject name in a group does not imply complete subject coverage. Language and aesthetic packs mainly teach study and analysis methods.

Source-access status is recorded individually. Some references were verified only through search metadata; blocked and oversized documents were not fully read or ingested.

Full Sinhala and Tamil answer translations are not included. Search aliases are provided; official resources offer medium-specific material.

Do not use stored data as a current timetable, fee, cutoff, deadline, eligibility ruling, political-office list or emergency warning.

## Files

- md/: one RAG-ready Markdown file per dataset.
- records.jsonl: one structured Q&A record per line.
- catalog.json: records, subject-search aliases, source access and coverage metadata.
- manifest.json: file checksums, counts and source registry.

## Sources and rights

Official sources were researched on 2026-10-24. Curriculum links establish subject orientation; original worked examples and answers are editorial content, not government-authored answer keys. See each source's access and edition notes.

These are original Orin notes and exercises. Linked third-party textbooks, papers and other works retain their own rights and are not relicensed by this dataset.

## RAG import

Run npm run knowledge:import for a dry run. npm run knowledge:import -- --apply adds or updates drafts in the configured Neon database. It does not publish automatically or call embedding providers. Review the material, then index and publish through Administration.
