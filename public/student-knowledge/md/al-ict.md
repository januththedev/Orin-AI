## AL ICT: data, networks, databases and programming: What does database normalisation try to reduce?

It organises relations to reduce problematic redundancy and update anomalies while preserving meaningful dependencies. Normal forms have precise conditions. Merely splitting one table into several tables does not prove that a design is well normalised.

## AL ICT: data, networks, databases and programming: How do a primary key and a foreign key differ?

A primary key uniquely identifies a row in its table. A foreign key constrains references to an appropriate key in another or the same table. A foreign-key column can contain repeated values unless another constraint prevents it.

## AL ICT: data, networks, databases and programming: How do TCP and IP differ conceptually?

IP supports addressing and delivery of packets across networks. TCP provides a reliable ordered byte-stream service over IP between endpoints. The layered model helps describe responsibilities; neither protocol by itself makes an application secure.

## AL ICT: data, networks, databases and programming: What is the difference between a stack and a queue?

A stack commonly follows last-in, first-out access. A queue commonly follows first-in, first-out access. Trace concrete insertions and removals to test understanding. The data structure's interface is distinct from its array or linked implementation.

## AL ICT: data, networks, databases and programming: What does Big-O notation express?

It describes an asymptotic upper-bound relationship for growth, such as how an operation count scales with input size under a model. It is not an exact running time in seconds, and constants and input characteristics still matter in practice.
